# XENOWAVE brand assets

This directory is reserved for approved XENOWAVE derivative assets. No graphical placeholder is permitted.

The official logo and alien symbol master is `docs/brand/references/xenowave_launcher_master.png`, confirmed by the brand owner on 2026-11-06. The previous composite reference panel was retired and removed at the owner's request; it must not guide new work or replace the implemented interface.

The launcher, themed, splash and store derivatives that are shipped with the app live with the Android resources (`app/src/main/res/mipmap-*` and `app/src/main/res/drawable-*`) and with the store metadata. Their provenance and content fractions are recorded in `../iconography/README.md`; no isolated official derivative file was available when they were produced.
